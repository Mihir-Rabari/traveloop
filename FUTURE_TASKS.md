# Future Tasks & Roadmap - Traveloop

This document outlines the planned tasks and future enhancements for the Traveloop platform.

## 🔗 API & Frontend Integration
- [ ] Integrate **TanStack Query** for server state management.
- [ ] Implement global request caching and prefetching.
- [ ] Add **optimistic updates** for trip and activity management.
- [ ] Setup a **WebSocket** layer for real-time trip collaboration.
- [ ] Implement a real-time sync mechanism for multi-device support.
- [ ] Add offline queue support for actions taken without internet.
- [ ] Implement API analytics and performance tracking.
- [ ] Add request retry queues for unreliable connections.
- [ ] Setup frontend error monitoring and logging (Sentry).

## 📧 Mail System
- [ ] Build production-grade responsive email templates.
- [ ] Add branded travel-themed email UI components.
- [ ] Setup mail queue workers using **BullMQ** and **Redis**.
- [ ] Implement retry mechanisms and open tracking.

## 🔐 Authentication & Security
- [ ] Implement **Google/GitHub OAuth**.
- [ ] Add device session management.
- [ ] Implement Multi-Factor Authentication (MFA).

- [ ] Real-time collaboration on shared trips.
